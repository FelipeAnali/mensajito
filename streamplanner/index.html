¿Cuentan como día rojo?
Días del mes separados por coma. En estos días no se descansa; si cae lunes, el descanso pasa al miércoles o al jueves. Los festivos siempre se marcan en el plan; con Sí también siguen las reglas de día rojo.

Crear el token (una sola vez)
  1. En github.com: tu foto → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Nombre: StreamPlanner. Vencimiento: el que prefieras (por ejemplo 1 año).
  3. Repository access → Only select repositories → elige solo mensajito.
  4. Permissions → Repository permissions → Contents → Read and write. Nada más.
  5. Toca Generate token, cópialo y pégalo arriba en Token. Anota la fecha de vencimiento en El token vence.
Suscribirse en el iPhone (una sola vez)
  1. Toca Suscribirme (aquí o en Semana → Calendario del iPhone) y luego Suscribirse → Guardar.
  2. Si no se abre: Ajustes → Apps → Calendario → Cuentas → Añadir cuenta → Otra → Añadir calendario suscrito, pega el enlace y toca Siguiente → Guardar.
  3. Importante: en Calendarios suscritos → tu calendario, desactiva Eliminar alertas.
El token se guarda solo en el navegador de este celular: no va en los respaldos ni en el calendario. Solo puede editar ese repositorio. Si pierdes el celular, bórralo en GitHub. El repositorio es público: el calendario lleva solo horarios, nunca direcciones.
